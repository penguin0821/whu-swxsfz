# legacy — 冻结的历史版本

这里是网站 v1–v5 的模板与构建脚本，仅作**演进记录**，已冻结，不用于生产。当前线上版本是仓库根目录的 `demo6_template.html` + `reinject6.py`。

| 版本 | 模板 | 构建脚本 | 这一版主要做了什么 |
|------|------|----------|--------------------|
| v1 | `demo_template.html` | — | 最初骨架：榕树主视觉 + 双色底 + 五段结构。 |
| v2 | `demo2_template.html` | `reinject.py` | 脊柱（spine）视觉、全屏搜索浮层、成员详情弹窗。 |
| v3 | `demo3_template.html` | `reinject3.py` | 胶囊导航 + 首屏语言门；榕树细线画框 + 破框全貌；蓝图网格 + 章节 HUD。 |
| v4 | `demo4_template.html` | `reinject4.py` | 首屏分层合成（亮雾天空 + 浮岛 + 前景枝）；编排式章节过渡 + 章内滚动视差；风动效。 |
| v5 | `demo5_template.html` | `reinject5.py`（+ `render5.sh`） | 首屏去边界线 + lerp 视差 + 鸟群；vw 字阶 + 满幅区块 + 逐词揭示；榕树贯穿四章作结构元素。 |
| **v6** | **`../demo6_template.html`** | **`../reinject6.py`** | **当前线上版**：鲜活浮岛、锥形气根、常驻磨砂顶栏、内嵌镂空旋转地球、sticky 面板、字体自同步子集化管线。 |

## 注意

- 这些脚本引用的是它们**当时**的相对路径与中间文件，在本仓库的新目录结构下不保证能直接运行。保留它们是为了记录"某一版效果/某个素材是怎么做出来的"。
- 各版之间的视觉与交互共识、踩坑经验，已沉淀进 `../docs/开发使用手册.md`，接手时看那份即可，不必逐个跑历史版本。
- 需要回溯某一版的完整产物时，看 Git 历史或对应 tag。
